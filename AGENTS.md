# DocBase Marketplace

DocBase CLI skill for AI agents.

## Skills

- `plugins/docbase-cli/skills/use/SKILL.md` — Search, read, create, and manage DocBase memos, comments, users, groups, tags, and attachments via CLI.

## Prerequisites

- [DocBase CLI](https://www.npmjs.com/package/@krayinc/docbase-cli) (`npm install --ignore-scripts -g @krayinc/docbase-cli`, requires Node.js 24 or later)
- Authenticated with DocBase CLI (`docbase auth login`)
